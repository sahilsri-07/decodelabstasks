# Task-2

## Data Classification using Artificial Intelligence

### Objective

Build a machine learning classification model using the Iris dataset.

### Algorithm Used

K-Nearest Neighbors (KNN)

### Libraries

- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

### Workflow

1. Load Iris Dataset
2. Split Data into Train/Test Sets
3. Perform Feature Scaling
4. Train KNN Classifier
5. Predict Test Data
6. Evaluate Model
7. Display Confusion Matrix

### Output

- Accuracy Score
- F1 Score
- Classification Report
- Confusion Matrix

### How to Run

```bash
pip install -r requirements.txt
python main.py
```
