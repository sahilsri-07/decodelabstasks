# Artificial Intelligence Internship Projects

A collection of Artificial Intelligence projects completed during my AI Internship at **DecodeLabs**. This repository demonstrates the fundamentals of AI, Machine Learning, and Recommendation Systems through hands-on implementation using Python.

---

## Internship Details

- **Organization:** DecodeLabs
- **Domain:** Artificial Intelligence
- **Language:** Python
- **Focus:** AI Fundamentals, Machine Learning, Recommendation Systems

# Projects

## Project 1: Rule-Based AI Chatbot

A simple chatbot that responds to predefined user inputs using rule-based logic.

### Features

- Interactive chatbot
- Handles greetings and common queries
- Exit command support
- Continuous conversation loop
- Dictionary-based response mapping

### Concepts Used

- Control Flow
- If-Else Statements
- Dictionaries
- Loops
- Functions

---

## Project 2: Data Classification using Machine Learning

A basic supervised learning project that classifies data using the Iris Dataset.

### Features

- Dataset loading
- Data preprocessing
- Train-Test Split
- Feature Scaling
- K-Nearest Neighbors (KNN)
- Model Evaluation
- Accuracy & Confusion Matrix

### Concepts Used

- Supervised Learning
- Classification
- Scikit-Learn
- StandardScaler
- KNN Algorithm

---

## Project 3: AI Recommendation System

A simple content-based recommendation engine that suggests items based on user interests.

### Features

- User preference input
- Content-based filtering
- Similarity matching
- Top-N recommendations
- Personalized suggestions

### Concepts Used

- Recommendation Systems
- TF-IDF
- Cosine Similarity
- Feature Extraction
- Content-Based Filtering

# Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/AI-Internship.git
```

### Navigate to the Repository

```bash
cd AI-Internship
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run a Project

```bash
python chatbot.py
```

or

```bash
python classification.py
```

or

```bash
python recommendation.py
```
